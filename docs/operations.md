# 札幌チェスクラブサイト 運用ガイド

非エンジニア向けの日常更新手順をまとめています。

すべての編集は **[Pages CMS](https://app.pagescms.org/kuramoto-to-the-moon/sapporo-chess-club/main)** から行います。GitHub アカウントとリポジトリへの招待が必要です。

---

## 必要なアカウント

| サービス | 用途 | 費用 |
|---|---|---|
| **GitHub** | コードホスティング + Pages CMS ログイン + デプロイ | 無料 |
| **Pages CMS** | ブラウザからコンテンツ編集 (GitHub でログイン) | 無料 |
| **GitHub Pages** | サイトホスティング (sapporochessclub.com) | 無料 |

カスタムドメインの維持費のみ (年間 1,000〜2,000 円程度)。HTTPS 証明書は GitHub Pages が自動発行。

## 日常タスク別の手順

### A. 例会日程を追加する

1. Pages CMS で **「スケジュール（例会）」** を開く
2. 右上の「新規」をクリック → 新しいファイルが作成される
3. 各フィールドを入力:
   - **日付**: カレンダーから選択
   - **開始時間 / 終了時間**: HH:MM 形式 (例: `09:00` / `15:00`)
   - **部屋番号**: 例: `810A`、`740`
   - **備考 (任意)**: 通常と違う部屋を使う日などに「注意：810Aではなく740」のように入力
4. 「保存」を押す → 自動で本番反映 (1〜2 分後)

> 曜日は日付から自動計算されるので入力不要です。
> スケジュール一覧ページには過去の日程も含めて全件表示されます。

---

### B. 大会の日程を追加する

複数日大会 (例: 土曜+日曜の 2 日連続) は **1 日 1 ファイル** 作成します。

1. Pages CMS で **「スケジュール（大会）」** を開く
2. 「新規」をクリック
3. 各フィールドを入力:
   - **開催日**: カレンダーから選択
   - **大会名 (日本語)**: 必須。例: `第32回 北海道チェス選手権`
   - **大会名 (English)**: 任意。例: `32nd Hokkaido Chess Championship`
   - **開始時間 / 終了時間**: HH:MM 形式
   - **部屋番号**: 例: `810A`
   - **備考 (任意)**: 参加費や持ち物などの特記事項
4. 保存

---

### C. 大会が終わったら結果を公開する

1. 結果 PDF (`*.pdf`) と棋譜 PGN (`*NoAnalysis.pgn` / `*Analysis.pgn`) を準備
2. Pages CMS で **「大会記録」** → 「新規」
3. 入力:
   - **大会名 (日本語)**: 必須。例: `第32回 北海道チェス選手権`
   - **大会名 (English)**: 任意
   - **開催日**: 大会初日
   - **要項 PDF / 結果 PDF / 棋譜 PGN**: 「ファイルをアップロード」→ `competition` フォルダにアップロード
   - **棋譜 PGN (解析付)**: 評価値コメント付きの棋譜があれば追加
4. 保存

> 一覧ページでは日付の新しい順に自動で並びます。

---

### D. お知らせを追加する

1. Pages CMS で **「お知らせ」** → 「新規」
2. 入力:
   - **公開日**: 新しい順に自動で並ぶ
   - **タイトル (日本語)**: 必須
   - **タイトル (English)**: 任意。空欄なら英語ページでは日本語タイトルが表示される
   - **本文 (日本語)**: 見出し・太字・リンク・箇条書き・表が使える
   - **本文 English (任意)**: 空欄なら英語ページでは「英語版はまだありません」の注記付きで日本語本文が表示される
3. 保存

> 公開日から **365 日経過すると自動で「アーカイブ」に移動**します。手動で何かする必要はありません。

---

### E. 会場・連絡先・参加費を変更する

1. **「サイト基本情報」** を開く
2. 該当フィールド (メール / 電話 / 施設名 / フロア / 住所 / アクセス / 参加費) を編集
3. 保存

---

### F. 講座情報を変更する

1. **「チェス講座」** から該当エントリを開く
2. タイトル / 説明文 / 外部 URL を編集
3. 外部 URL を設定すると講座セクションに「詳細を見る ↗」リンクが表示される

---

### G. 外部リンクを追加・削除する

1. **「外部リンク」** を開く
2. 「リンク一覧」に追加 (タイトル日英 + URL) または削除
3. 保存

> 日本チェス連盟 (JCA) のリンクはフッターに固定表示されており、CMS からは編集しません。

## トラブルシューティング

### 保存したのにサイトに反映されない
- GitHub Actions のビルドが完了するまで 1〜2 分かかります
- ブラウザをハードリロード (Ctrl+Shift+R / Cmd+Shift+R)
- それでも反映されない場合は管理者に連絡

### 時刻の入力形式
- HH:MM (24 時間制) を推奨。例: `09:00`、`14:30`
- スキーマ上は自由入力ですが、表示の統一のため `09:00` のようにゼロ埋めしてください

### 過去の例会日程は消すべき？
- 消さなくて OK です。過去の予定もスケジュール一覧に表示されますが、活動記録として残ります
- 誤って削除した場合は GitHub の履歴から復元できます。管理者に連絡してください

### CMS にログインできない
- GitHub アカウントでログイン → リポジトリへの招待が必要。管理者に依頼してください

### iOS でホーム画面に追加したアプリが白くなる
- 画面をタップすると数秒後にリロードされることがあります
- 改善しない場合はアプリを閉じて再度開いてください
- iOS の WebView の既知の挙動で、サイト側の問題ではありません

## 管理者向け補足

### Pages CMS のスキーマ
`.pages.yml` で定義。`src/content.config.ts` (Astro 側スキーマ) と必ず一致させること。スキーマがずれると CMS の保存時にデータが欠落する事故が起きる。

### デプロイ
`main` への push で GitHub Actions が自動ビルド → GitHub Pages にデプロイ。失敗時は GitHub の Actions タブで確認。

### カスタムドメイン
- DNS: GitHub Pages の IP を A レコードで指定
- リポジトリの Settings → Pages → Custom domain に `sapporochessclub.com`
- `public/CNAME` にドメインを記載
- `astro.config.mjs` の `site` をドメインに合わせる
