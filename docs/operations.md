# 札幌チェスクラブサイト 運用ガイド

非エンジニア向けの日常更新手順をまとめています。

すべての編集は **[Pages CMS](https://app.pagescms.org/kuramoto-to-the-moon/sapporo-chess-club/main)** から行います。GitHub アカウントとリポジトリへの招待が必要です。

---

## 必要なアカウント

| サービス | 用途 | 費用 |
|---|---|---|
| **GitHub** | コードホスティング + Pages CMS ログイン + デプロイ | 無料 |
| **Pages CMS** | ブラウザからコンテンツ編集 (GitHub でログイン) | 無料 |
| **GitHub Pages** | サイトホスティング | 無料 |
| **Formspree** | 大会申込フォーム送信先 (管理者のみ) | 無料 (月 50 通まで) |

カスタムドメインを使う場合はドメインの購入・維持費のみ (年間 1,000〜2,000 円程度)。GitHub Pages 側の設定は無料。HTTPS 証明書も自動発行。

| Pages CMS のメニュー | 内容 |

| **サイト基本情報** | メールアドレス、電話番号、会場、参加費 |

## 日常タスク別の手順

### A. 例会日程を追加する

1. Pages CMS で **「スケジュール（例会）」** を開く
2. 「例会日程」配列の末尾に新しい項目を追加
3. 各フィールドを入力:
   - **日付**: カレンダーから選択
   - **開始時間 / 終了時間**: HH:MM 形式 (例 09:00 / 15:00)
   - **部屋番号**: 例 810A、740 など
   - **会場**: 「かでる2.7」/「Kaderu 2.7」 (毎回同じ)
   - **備考**: 通常室と違う部屋を使う日などに「注意：810Aではなく740」のように入力 (任意)
4. 「保存」を押す → 自動で本番反映 (1〜2 分後)

> 曜日は日付から自動計算されるので入力不要です。

---

### B. 大会の日程を追加する

複数日大会 (例: 土曜+日曜の 2 日連続) は **1 日 1 エントリ** 作成します。

1. Pages CMS で **「スケジュール（大会）」** を開く
2. 「大会日程」配列に大会の各日を追加
3. 各日のフィールド:
   - **開催日 / 開始時間 / 終了時間 / 部屋番号 / 会場**: 例会と同じ
   - **大会シリーズ**: 北海道選手権 / 札幌サマー / 札幌オータム / その他 から選択。大会名は自動生成される
   - **回数 (任意)**: 「第 N 回」の N。入力すると「第32回 北海道チェス選手権」のように表示
   - **大会名 (その他の場合のみ)**: シリーズが「その他」の場合だけ日英を入力
4. 申込フォームを出したい場合 (**初日にのみ設定**):
   - **Formspree ID**: Formspree 管理画面でフォームを作って取得した ID
   - **申込開始日 (任意)**: 受付開始日。未指定なら即時開始
   - **申込締切日 (任意)**: 未指定なら **開催日の前々日 23:59 が自動で締切**
5. 保存

> Formspree ID は **大会の初日のエントリにだけ** 設定してください。複数日に設定するとフォームが重複表示されます。

---

### C. 大会が終わったら結果を公開する

1. Pages CMS で **「スケジュール（大会）」** を開き、終わった大会のエントリを **削除**
2. 結果 PDF (`*.pdf`) と棋譜 PGN (`*NoAnalysis.pgn` / `*Analysis.pgn`) を準備
3. **「大会記録」** で「新規」 → 入力:
   - **大会シリーズ / 回数**: スケジュールと同じ選択肢。大会名は自動生成される
   - **開催日**: 大会初日
   - **要項 PDF / 結果 PDF / 棋譜 PGN**: 「ファイルをアップロード」 → `competition` フォルダにアップロード
   - 「棋譜 PGN (解析付)」もあれば追加
4. 保存

> 一覧ページでは **日付の新しい順** に自動で並びます。年やソート順を入力する必要はありません。

---

### D. お知らせを追加する

1. Pages CMS で **「お知らせ」** を開く
2. 「新規」をクリック
3. 入力:
   - **公開日**: YYYY-MM-DD 形式。新しい順に自動で並ぶ
   - **タイトル (日本語)**: 必須
   - **タイトル (English)**: 任意。空欄なら英語ページでは日本語タイトルが表示される
   - **概要 (日本語)**: 一覧ページに表示される 1〜2 行の説明。必須
   - **概要 (English)**: 任意
   - **本文**: markdown で記述 (太字、リンク、箇条書き等が使える)
   - **本文 English**: 任意。空欄なら英語ページでは「日本語で表示されます」の注記付きで日本語本文が表示される
4. 保存

> 公開日から **365 日経過すると自動で「アーカイブ」に移動**します。編集者が手動で何かする必要はありません。アーカイブが存在する場合のみ、お知らせ一覧ページの末尾にアーカイブへのリンクが表示されます。

> 英語の自動翻訳機能は現在無効です。英語版が必要な場合は手動で入力してください。自動翻訳を有効化するには管理者が API キーを設定する必要があります (後述)。

---

### E. 会場・連絡先・参加費を変更する

1. **「サイト基本情報」** を開く
2. 該当フィールド (メール / 電話 / 会場 / 参加費) を編集
3. 保存

---

### F. 講座情報を変更する

1. **「チェス講座」** から該当エントリを開く
2. タイトル / 説明文 / 外部 URL を編集
3. 外部 URL を設定すると講座セクションに「詳細を見る」リンクが表示されます

---

### G. 外部リンクを追加する

1. **「外部リンク」** を開く
2. 「リンク一覧」配列に追加 (タイトル + URL)
3. 保存

> 日本チェス連盟 (JCA) のリンクは Footer に固定表示されており、CMS からは編集しません。

## トラブルシューティング

### 保存したのにサイトに反映されない
- GitHub Actions のビルドが完了するまで 1〜2 分かかります
- 画面をハードリロード (Ctrl+Shift+R / Cmd+Shift+R)
- それでも出ない場合は管理者に連絡

### 入力した時刻フォーマットがエラーになる
- HH:MM (24 時間制) で入力してください。例: `09:00`、`14:30`
- `9:00` は NG → `09:00` で

### 過去の例会日程を消したい
- **削除しないでください**。過去の予定はサイト上には表示されますが、データとして残しておくことで過去の活動記録になります。誤って削除した場合は GitHub の履歴から復元できますが、管理者に連絡してください。

### 写真や画像をアップロードしたい
- 現在 CMS では大会関連 PDF / PGN ファイルしか扱えません。サイトに画像を追加したい場合は管理者に連絡してください。

### CMS にログインできない
- GitHub アカウントでログイン → リポジトリへの招待が必要です。管理者に依頼してください。

### iOS PWA (ホーム画面に追加したアプリ) で画面が白くなる
- 画面をタップしてみてください。数秒後にリロードされることがあります
- 改善しない場合はアプリを閉じて再度開いてください
- これは iOS の WebView の既知の挙動で、サイト側の問題ではありません

## 管理者向け補足

### Pages CMS のスキーマ
すべて `.pages.yml` で定義。`src/content.config.ts` (Astro 側スキーマ) と必ず一致させること。スキーマがずれると CMS の保存時にデータが落ちる事故が起きる。

### 英語自動翻訳 (現在無効)
お知らせの ja → en 自動翻訳ワークフロー (`translate-announcements.yml`) は存在するが、現在は**手動トリガー (`workflow_dispatch`) のみ**で自動実行されない。

自動化するには:
1. GitHub Secrets に `ANTHROPIC_API_KEY` または `DEEPL_API_KEY` を登録
2. `.github/workflows/translate-announcements.yml` の `on:` トリガーに `push` を追加
3. API 利用料が発生する (DeepL Pro: 月 $5〜 / Claude API: 従量課金)

### デプロイ
`main` への push で GitHub Actions が build → GitHub Pages にデプロイ。失敗時は Actions タブで確認。

### カスタムドメインの設定
1. ドメインを購入 (例: sapporo-chess.org)
2. DNS で GitHub Pages の IP を指定 (A レコード or CNAME)
3. リポジトリの Settings → Pages → Custom domain にドメインを入力
4. 「Enforce HTTPS」にチェック (Let's Encrypt 証明書が自動発行)
5. `astro.config.mjs` の `site` を新ドメインに変更
