## 技術スタック

```
┌─────────────────────────────────────────────────┐
│                  ビルド時 (SSG)                    │
│                                                   │
│  Astro 6          フレームワーク (静的サイト生成)     │
│  Tailwind v4      CSS (インライン化して配信)         │
│  Svelte 5         ApplicationForm のみ使用         │
│  TypeScript        型安全                          │
│  marked           Markdown → HTML 変換             │
│                                                   │
│  ビルド成果物: 56 ページの静的 HTML                   │
│  CSS: 全ページにインライン (外部 CSS ゼロ)            │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│               ブラウザ側 (ランタイム)                │
│                                                   │
│  全ページ共通 JS:                                   │
│    HamburgerMenu   <dialog> ベース (vanilla)       │
│    Header          headroom (スクロール非表示)       │
│    ScrollTop       ↑ ボタン (Svelte, client:idle)  │
│    合計: ~4 KB gzip                                │
│                                                   │
│  /schedule のみ (申込受付中の時だけ):                  │
│    ApplicationForm  Svelte + bits-ui Dialog        │
│    合計: ~41 KB gzip (client:visible で遅延ロード)   │
│                                                   │
│  /tournaments のみ:                                │
│    TournamentYearFilter  vanilla listbox           │
│    PGN ダウンロード       fetch + Blob              │
│    合計: ~1 KB (HTML 内インライン)                    │
└─────────────────────────────────────────────────┘
```
